亦可以直接使用 document、window、fetch 等 browser APIs。
app.registerTool 可用嚟建立一個「讓 AI 新增工具」嘅工具，但預設不提供。
成功回傳值必須可以 JSON 序列化；undefined 會轉成 null。

Tools
啟停即時保存；編輯內容需按儲存。切換 browser tab 不會同步另一分頁嘅 registry。











Parameters



支援巢狀 object／array、enum、限制及組合 Schema；透過原始 JSON 編輯。UI 不會自動填入 default，亦唔會轉換參數型別。外部 $ref 不支援。


JavaScript
函數 body；可用 args、app，可 await，可 return。儲存只檢查語法，不執行。
